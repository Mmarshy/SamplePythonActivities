# Distance Calculator

This is a Python code for finding the distance between two points.

## **How to Run the Code**

First, run the Python program. You will then be asked to enter the X1, X2, Y1, and Y2 coordinates. Enter the values of the coordinates when asked.

## **Input Needed**

- X1
- X2
- Y1
- Y2

## **Output**

The program will display the distance between the two points, rounded to 2 decimal places.

## **Process**

1. Get the coordinates of the two points.
2. Calculate the difference between X2 and X1.
3. Calculate the difference between Y2 and Y1.
4. Square both differences.
5. Add them together.
6. Find the square root.
7. Round the answer to 2 decimal places.
8. Display the answer.
